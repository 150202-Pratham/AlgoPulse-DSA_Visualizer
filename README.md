# AlgoPulse - DSA Visualizer

Live demo: https://algo-pulse-dsa-visualizer.vercel.app/

AlgoPulse is a browser-based DSA visualization project built to make sorting algorithms easy to understand through interactive animation and real-time visual feedback.

## What is implemented

This project currently includes:

- A modern landing page with a dark UI and responsive layout
- A sorting visualizer workspace
- Bar-based sorting animations
- Custom array input support
- Randomize and reset controls
- Adjustable array size and delay speed
- Sorting algorithms:
  - Bubble Sort
  - Insertion Sort
  - Heap Sort
  - Merge Sort
  - Quick Sort

## Tech stack

- HTML5
- CSS3
- JavaScript
- D3.js

## Run locally

```bash
npm install
npx serve .
```

Then open the local URL shown by the server in your browser.
